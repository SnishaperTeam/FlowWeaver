llm_app.txt — 应用层（main.go + app/）
========================================

职责：把 Wails v3 应用、托盘、窗口、系统代理、自启、更新、规则热加载
全部串起来，对前端暴露的方法都在 *App 上（前端经 bindings.ts 调用）。


main.go（入口，178 行）
-----------------------
  - 顶层 recover → ForceCleanup + 强制关系统代理（防崩溃后代理残留）
  - application.Options：Name="snishaper"，Description、图标、SingleInstance
    （UniqueID "com.snishaper.desktop"，二次启动 → RevealMainWindow）
  - BuildSystemTray 建托盘；Window.NewWithOptions 建主窗口（frameless，
    Title "SniShaper"，ShouldStartHidden 决定是否直接隐藏）
  - AttachMainWindowHandlers 挂 WindowClosing hook（关窗到托盘的关键，见
    app_ui_wails.go 注释：必须用 hook 而不是 listener，否则与运行时的
    destroy 处理竞争，关窗会把窗口干掉导致无法再呼出 UI）
  - wails3 单实例握手在非 dev 会话下才启用（dev 会直接退出第二次实例）


app/ 按主题分组
----------------
  核心结构与生命周期
    app.go             App 结构体、启动/关闭 hook、emitFrontendState（状态事件）
    app_api.go         ★ 所有导出 API：NewApp、StartProxy/StopProxy、端口、
                       SOCKS5、代理模式、语言/主题、TUN、证书（InstallCA/
                       ExportCert/RegenerateCert）、站点组/上游/DNS 节点/
                       ECH/NAT64 CRUD、CF IP 池、日志、统计、版本、QuitApp。
                       前端 bindings.ts 里的每个函数基本对应这里一个方法。
    app_config_only.go 无网络环境下的精简 API 子集
    app_version.go     版本号（含 Package.appxmanifest 解析）

  窗口 / 托盘 / UI
    app_ui_wails.go    ensureMainWindow（休眠后重建窗口）、AttachMainWindowHandlers、
                       handleWindowClosing（close-to-tray / hibernate 判定）
    app_tray.go        托盘图标、菜单、tooltip（"SniShaper"）
    app_headless.go    无头/休眠状态管理（前端休眠 → 关 webview 省资源）

  系统集成
    app_system.go      系统代理开关（写注册表，需管理员；改它必须验证代理开关）
    app_port.go        端口占用检查/释放
    app_ipv6.go        IPv6 可用性探测 + 周期监控
    app_log.go         日志缓冲、LogFileInfo、清理旧日志
    app_crash.go       崩溃日志（配合 common/crashlog.go）
    app_diag.go        GetProxyDiagnostics / ProxySelfCheck（自检，CLI 也用）

  自启 / 单实例
    autostart_windows.go | _linux.go | _darwin.go | _stub.go
                       开机自启（Windows 注册表 / Linux .desktop / macOS）
    single_instance_recovery_*.go  单实例锁损坏后的恢复
    instance_listener_*.go         实例监听（收到二次启动信号）

  规则 / 更新 / 进化
    app_rules_watch.go   监听 rules/config.json 变化 → 热加载
    app_rules_update.go  UpdateRules（更新 GFWList 类规则；线上拉取已移除，
                         现在只读本地 gfwlist_cache.txt）
    app_update.go        检查/下载更新（ReleaseAsset、渠道、下载源）
    app_update_install_windows.go  Windows 安装（便携版 PowerShell 更新脚本）
    app_evolution.go     规则进化测试的桥接（调 evolution/）
