llm_frontend.txt — 前端（frontend/）
=====================================

技术栈：React 19 + TypeScript 6 + Vite 8 + MUI v9（emotion）+ Wails v3 运行时。
HashRouter 路由，页面全部 lazy + Suspense。路径别名 @/ → ./src/。


关键文件
--------
  index.html            标题 "SniShaper"
  src/main.tsx          挂载入口
  src/App.tsx           ★ 路由表（lazy 导入 10 个页面）、主题/语言初始化、
                        事件订阅：app:state / app:state_changed → 全局状态刷新；
                        首次进入经 Welcome 选语言
  src/api/bindings.ts   ★ 与后端的唯一通道：Call.ByName("snishaper/app.App.*")。
                        每个导出函数对应 app/app_api.go 的一个 *App 方法。
                        EventsOn 封装 Wails 事件。
                        （后端方法改名 → 这里必须同步，否则运行时才炸）
  src/i18n/I18nContext.tsx   i18n provider：t(path, params)，zh/en/ru 三份
  src/i18n/locales/{zh,en,ru}.json   文案；缺失 key 会原样返回 key 本身，
                        所以 t(key)||'fallback' 是死代码，正确写法
                        label === key ? fallback : label；新增文案三份同改
  src/theme/index.ts    MUI 主题（暗色为主）
  src/lib/utils.ts / toast.ts / icons.tsx / useClickOutside.ts   工具
  src/components/       共用组件
      WindowControls.tsx   无边框窗口的最小化/关闭按钮
      Sidebar.tsx          侧边导航
      Modal.tsx / ToastProvider.tsx   弹窗与轻提示
      RuleForm.tsx / ECHProfileForm.tsx / NAT64ProfileForm.tsx   表单
      ui/Autocomplete.tsx  封装的联想输入


页面（src/pages/）
------------------
  Welcome     首次启动：选语言
  Dashboard   主页：代理/TUN 状态、开关、流量统计、自检入口
              （订阅 app:state_changed）
  Proxies     上游 / Cloudflare 配置、优选 IP 池、代理模式
  Rules       站点分组 CRUD、规则导入导出（订阅 app:rules_changed）
  Routing     自动路由（GFWList）配置与实时路由事件（订阅 app:route）
  DNS         DNS 节点 CRUD、测速、优先级排序
  Evolution   规则进化测试 UI（订阅 evolution:progress / evolution:complete）
  Logs        日志查看（app/core 日志文件、清空、打开文件）
  Settings    端口、SOCKS5、TUN、自启、主题、语言、更新选项
  About       版本、检查更新、下载/安装（订阅 update:download_progress）


状态同步模式
------------
  后端 emitFrontendState() → 事件 app:state / app:state_changed 携带整包状态
  → App.tsx / Dashboard.tsx 收到后 setState 刷新。
  单向：前端改配置一律先调 bindings 里的异端函数，成功后等事件回推，
  不要自己乐观更新后不管。

改动注意
--------
  - 改事件名/结构 → 验证 app:state、app:state_changed
  - 改任何文案/aria/placeholder → zh/en/ru 三份同 commit 改完，
    跑 ./node_modules/.bin/tsc --noEmit（vite build 不做严格类型检查）
