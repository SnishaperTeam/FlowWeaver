# Приложение в строке меню macOS (FlowWeaverBar)

В macOS FlowWeaver поставляется как **приложение в строке меню**: Swift-пакет в `macos/` (FlowWeaverBar) отображает статус и управляет режимами, а сам прокси-движок работает в headless-бинарнике `flowweaver`, встроенном в приложение.

## Архитектура

```
FlowWeaver.app
├── Contents/MacOS/FlowWeaverBar            # приложение строки меню (Swift, SPM)
├── Contents/Resources/bin/flowweaver       # headless CLI (Go, прокси-движок)
└── Contents/Info.plist                    # LSUIElement=true: только строка меню, без иконки в Dock
```

- Приложение строки меню **не содержит прокси-логики**: запуск/остановка сервиса, переключатели прокси и системного прокси выполняются через подкоманды CLI (`flowweaver start/stop/proxy on/off/sysproxy on/off/diag`).
- Опрос статуса использует стабильный JSON-контракт `flowweaver status --json` (каждые 3 секунды); человекочитаемый текст не парсится.
- TUN, правила, подписки, ECH и всё остальное предоставляет процесс CLI; описание команд — `flowweaver help`.

## Сборка

Требования: macOS 13+, Xcode Command Line Tools (swift 5.9+), Go 1.27+.

```bash
# Полная упаковка (сборка приложения + headless CLI, сборка .app и zip)
macos/scripts/bundle-app.sh

# Только приложение строки меню
cd macos && swift build -c release
```

Результат: `build/bin/macos/FlowWeaver.app` и `FlowWeaver-macos-<arch>.zip`.

CI собирает и упаковывает на нативных runner'ах Apple Silicon и Intel (job `darwin` в `.github/workflows/build.yml`).

## Установка

1. Скачайте `FlowWeaver-macos-<arch>.zip` и распакуйте.
2. Перетащите `FlowWeaver.app` в `/Applications` (или `~/Applications`).
3. Первый запуск: **сборки не подписаны и не нотаризованы**, Gatekeeper их заблокирует. Разрешите одним из способов:
   - ПКМ по `FlowWeaver.app` → «Открыть» → подтвердить (рекомендуется — разрешение только для этого приложения);
   - или Системные настройки → Конфиденциальность и безопасность → уведомление внизу → «Открыть всё равно».
4. Иконка ⬢ в строке меню означает, что приложение запущено.

## Обновление

1. Закройте приложение строки меню (меню → Завершить FlowWeaver).
2. Если сервис запущен, сначала остановите его (закрытие приложения не останавливает отдельный процесс сервиса): `Contents/Resources/bin/flowweaver stop`.
3. Замените старый `FlowWeaver.app` новым.
4. Откройте приложение снова.

Конфигурация и журналы хранятся рядом с бинарником по соглашениям CLI, поэтому обновление **никогда не удаляет** пользовательские данные.

## Удаление

1. Закройте приложение строки меню и остановите сервис (см. выше).
2. Удалите `FlowWeaver.app`.
3. При необходимости вручную выключите системный прокси: Системные настройки → Сеть → Прокси.
4. При желании удалите каталоги конфигурации и журналов, созданные CLI (`config/`, `rules/`, `log/` рядом с бинарником).

## Ограничения

- **Без подписи и нотаризации**: после каждого обновления нужно заново разрешать Gatekeeper.
- Процессу сервиса (CLI) нужны права администратора для TUN и системного прокси; в macOS системный прокси применяется через `networksetup`, TUN — через utun; возможны запросы авторизации.
- Приложение строки меню предоставляет базовое управление (сервис, прокси, системный прокси, диагностика, журналы); для полного набора функций используйте CLI.
- Подробности поддержки платформ — в [Platform_RU.md](Platform_RU.md).
